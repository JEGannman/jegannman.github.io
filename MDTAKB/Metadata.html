Purpose

Descriptive information about datasets is called metadata. When care is taken to provide detailed metadata on organizational datasets, MDTA GIS users have the necessary information available to evaluate the most appropriate datasets for the intended purpose. An item's metadata may include information about how accurate and recent the data is, restrictions associated with using and sharing the data, important processes in its life cycle such as generalizing features, and so on.

This page describes how to edit and view metadata in ArcGIS Pro desktop software, and view metadata in MDTA's ArcGIS Portal website. Metadata should be completed for each feature class and table in an enterprise geodatabase within MDTA's ArcGIS Enterprise system.

The following two steps are recommended prior to working with GIS datasets and their metadata.

Setting Metadata Style in ArcGIS Pro

MDTA has standardized on the ISO 19115/19139 metadata standard. Although this standard will be used, it is not mandatory to enter all the ISO metadata requirements to be considered “valid” by the ArcGIS software. Thus, after entering metadata, a user will still likely see multiple red “x” marks in ArcGIS Pro on sections where it deems metadata is insufficient (see Figure 1). This is acceptable so long as the MDTA recommended metadata (specified in this document) is populated.

To edit or view ArcGIS metadata in the ISO format, ArcGIS Pro (version 2.5+) must first be configured. Perform the following steps:

  1. Open ArcGIS Pro.
  2. Click on the Project tab. (Figure 2)
  3. Click on Options on the left-hand pane.
  4. In the Options popup, click on Metadata, then select ISO 19139. (Figure 3)
  5. Click OK.

Tip: Use the following link to access ESRI’s help page for ISO metadata Esri Help Page

Disable Geoprocessing History in Metadata

To avoid cluttering a feature class’s metadata with each geoprocessing operation performed, disable the Write geoprocessing operations to dataset metadata option in ArcGIS Pro as follows:

  1. Open ArcGIS Pro
  2. Click on the Project tab (Figure 4)
  3. Click on Options on the left-hand pane.
  4. In the Options popup, click on Geoprocessing, then uncheck Write geoprocessing operations to dataset metadata. (Figure 5)
  5. Click OK.
  6. Continue with any geoprocessing, editing, or mapping of the datasets.

Tip: see Esri's help page for more details.

MDTA's Template

To provide a starting point and to ensure consistent use limitations are applied across all datasets, the MDTA metadata template should be applied before populating metadata on a feature class. Applying a template after beginning to populate the target feature class’s metadata will cause it to be overwritten.

Tip: see Esri's help page for step-by-step instructions to apply a metadata template.

MDTA's standard template can be obtained here.

Tip: at ArcGIS Pro 2.5, when importing the MDTA metadata template, in The type of metadata to import drop down list, select Discover the type for me. Otherwise an error may be thrown. See Figure 6.

Copying Metadata

To ease the effort of entering metadata, metadata can be copied from one feature class with existing metadata to another. See ESRI help for details on copying metadata.

To edit metadata in ArcGIS Pro:

  1. Open ArcGIS Pro (Version 2.5 +), and open or start a new project.
  2. Open the Catalog pane.
    • Important Note: metadata can be created in layers in ArcGIS Pro projects, or on the layers in the geodatabase. MDTA metadata should be developed and stored in the geodatabase. So, be sure to select the layer from the Catalog pane database connection, not from the layers in the map.
  3. Navigate to the feature class of interest.
  4. Right click on the item and select Edit Metadata. (Figure 7)
  5. In the panes that open, navigate to the recommended metadata elements listed in the previous section (Table 1 above), click it, and enter the appropriate content.
  6. Complete entry of information for each recommended metadata element (Table 1 above). (Figure 8)
  7. Periodically, and upon completion, click the Save button in the Manage Metadata section of ArcGIS Pro’s menu ribbon. This will save edits to the geodatabase. (Figure 9)

ArcGIS Portal

Metadata populated for a feature class within an enterprise geodatabase can be viewed in MDTA's ArcGIS Portal following the publication of the feature class as a feature layer. Feature layer metadata can be viewed without any GIS software by accessing MDTA's ArcGIS Portal using a web browser. To view feature layer metadata in MDTA's ArcGIS Portal, perform the following steps:

  1. Open a web browser and navigate to MDTA's ArcGIS Portal, and sign in. See the ArcGIS Portal Access Guide for details on how to access MDTA's Portal site.
  2. Search for or navigate to content item of interest. Click on the Feature Layer version of the item to go to its details. (Figure 10)
  3. Within the feature layer, for the individual layer(s) of interest, click the Metadata button. (Figure 11)
  4. The new browser window that opens contains the feature class metadata from the geodatabase. Anytime the feature class's metadata is edited in the geodatabase, the updates are reflected in this page. (Figure 12)
    • Note: as of ArcGIS Enterprise 10.7.1 not all metadata fields are viewable through Portal. Specifically, attribute-level metadata is not present.

ArcGIS Pro

To view metadata in ArcGIS Pro:

  1. Ensure the metadata style is set to ISO as described in the above section Setting Metadata Style in ArcGIS Pro. Otherwise, not all the metadata elements will be displayed.
  2. Open the Catalog pane.
  3. Navigate to the feature class of interest.
  4. Right click on the item and select View Metadata. (Figure 13)
  5. The metadata will be viewable in the Catalog pane. (Figure 14)

 Description

A more detailed narrative of the feature.

A geospatial data layer of features representing Intelligent Transportation Systems devices maintained by the Maryland Transportation Authority (MDTA). Intelligent Transportation Systems (ITS): these networks support roadway ITS devices managed through the Coordinated Highways Action Response Team (CHART) Advanced Transportation Management System (ATMS), including Closed-Circuit Television (CCTV), Dynamic Message Sign (DMS), Toll Rate Signs (TRS), Highway Advisory Radio (HAR), Roadway Weather Information System (RWIS), and vehicle detection. CHART servers are located on the Maryland Department of Transportation (MDOT) enterprise network with local CHART web server and operator workstations at the main Authority Operations Center (AOC) central facility at 2330 Broening Hwy. In addition, the MDTA employs stopped vehicle detection using video analytics, and has several travel time reader sites which deposit data into the CHART database and is combined with other travel time data from INRIX to support the dissemination of travel time information to DMSs throughout the State of Maryland. (Source: 2019 MDTA Intelligent Transportation Systems Strategic Plan)
