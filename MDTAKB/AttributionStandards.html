Subtypes

Within the MDTA Enterprise GIS, subtypes are used to identify distinct groups of assets within a feature class in which multiple asset groups are combined. The ITSDevice feature class is an example where nearly 20 different device asset groups are combined and differentiated by the subtyped ASSET GROUP field. If a feature class is dedicated to one asset group (ex. Noise Barriers), a subtyped attribute is not required.

Default Values

Default values populate automatically when a new feature is added to a dataset. Because default values auto-populate, they should be used sparingly and are most appropriate for attributes for which specific information is not commonly available or for attributes that are typically the same across an entire dataset. Appendix B lists all default values currently specified within the MDTA Enterprise GIS system.

Unknown, Verified, and NULL Attribute Values

In some instances, attributes values will be unknown, unverified, null, or otherwise not applicable within a given dataset. The following standards describe how to update these attributes (Table 17).

Attribute Value

Update Instructions

NULL

Numeric, Date and non-domain-controlled Text fields should be left NULL when they have not been assessed for a valid input value.

Unverified

Unverified should be used to indicate that the valid input value has not been verified. This value can be used to flag text attributes for further review.

Unknown

Unknown should be used to indicates that an attribute has been intentionally reviewed, field or plan inspected, and the appropriate attribute value is still unknown.

Not Applicable

Not Applicable should be used when an attribute does not apply to a given asset.

No Link

No Link should be used within any hyperlink fields to indicate that no hyperlink exists for a given link attribute.

No Sheet

No Sheet should be used within the PLAN SHEET field to indicate that no sheet has been identified.
