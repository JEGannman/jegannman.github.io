Table B3: Facilities Data Default Values

The descriptions for all minimum standard and recommended attribute fields are listed in Table C1 below. These descriptions should be referenced when updating the attribute descriptions in the Metadata for MDTA datasets.

Attribute Name

Attribute Alias

Description

abandoned_date

ABANDONED DATE

ABANDONED DATE is used to record the date that an asset was abandoned-in-place, if applicable.

accepted_for_maint_date

ACCEPTED FOR MAINTENANCE DATE

ACCEPTED FOR MAINTENANCE DATE is used to record the date that MDTA assumed maintenance responsibility for a newly installed asset per the installation contract terms, if applicable.

access_height

ACCESS HEIGHT

ACCESS HEIGHT is used to record the height of the physical access point for an asset.

access_width

ACCESS WIDTH

ACCESS WIDTH is used to record the width of the physical access point for an asset.

amperage

AMPERAGE

AMPERAGE is used to record the electrical current in amps (amperes) of an asset.

asset_group

ASSET GROUP

ASSET GROUP is a subtype attribute used to classify and/or group similar assets (ex. Closed Circuit Cameras, Electric Vehicle Charging Stations). The choice of ASSET GROUP is dependent on the feature class the asset is being collected into.

asset_id

ASSET ID

ASSET ID is used to record a unique identifier for each asset following the format <PREFIX>-<unique number> (ex. ELECD-001, ELECD-002, etc.)

asset_notes

ASSET NOTES

ASSET NOTES is used as-needed to capture data not found in other fields or information from migrated data that does not fit into existing fields. ASSET NOTES is also used to flag new values not found in existing domains for later update.

asset_type

ASSET TYPE

ASSET TYPE is a domain-controlled attribute that is used to further sub-classify specific asset types within an asset group. The choice of ASSET TYPE is dependent on the feature class the asset is being collected into as well as an asset’s ASSET GROUP value. The following sections represent the feature classes and the tables contained within each section list the ASSET TYPE options for each ASSET GROUP value.

barcode

BARCODE

BARCODE is used to record the unique barcode number associated with an asset.

building_GUID

BUILDING GUID

BUILIDNG GUID is used to Global ID of a facility asset’s related building feature.

building_ID

BUILDING

IDENTIFIER

BUILDING IDENTIFIER is a domain-controlled attribute that is used to identify the building in which a facility asset is located.

circuit_number

CIRCUIT NUMBER

CIRCUIT NUMBER is used to record the electrical circuit number associated with an asset.

communication_type

COMMUNICATION TYPE

COMMUNICATION TYPE is a domain-controlled attribute used to record the type of data communication method that an asset utilizes (ex. Cellular, Infrared, Microwave, Radio, Wireless, etc.).

compilation_source

COMPILATION SOURCE

COMPILATION SOURCE is used to record the primary source(s) that were used to compile the asset.

contract_number

CONTRACT NUMBER

CONTRACT NUMBER is used to record the contract number(s) associated with an asset.

county

COUNTY

COUNTY is a domain-controlled attribute used to record the county (or city in the case of Baltimore City) and state within which an asset resides (ex. Anne Arundel – MD, Montgomery – MD, Baltimore City – MD, etc.

created_by

CREATED BY

The CREATED BY attribute is auto-populated when a new record is added to a feature class in the database and should not be edited by users.

created_date

CREATED DATE

The CREATED DATE attribute is auto-populated when a new record is added to a feature class in the database and should not be edited by users.

descriptive_location

DESCRIPTIVE

LOCATION

DESCRIPTIVE LOCATION is a text field to show a specific location of facility assets.

diameter

DIAMETER

DIAMETER is used to record the physical diameter of an asset.

enclosure_rating

ENCLOSURE RATING

ENCLOSURE RATING is used to record the rating (ex. NEMA rating) associated with structural assets.

facility

FACILITY

FACILITY is a domain-controlled attribute used to identify the MDTA facility where the asset is located.

feed_link

FEED LINK

FEED LINK is used to record the hyperlink to an asset’s video feed, if applicable (ex. CCTV feed).

field_verified_by

FIELD VERIFIED BY

FIELD VERIFIED BY is used to record the name of the individual (or organization/group) who field verified the asset.

field_verified_date

FIELD VERIFIED DATE

FIELD VERIFIED DATE is used to record the date that an asset was last field verified. The FIELD VERIFIED DATE attribute only applies to assets that have a FIELD VERIFIED BY value.

floor_ID

FLOOR

IDENTIFIER

FLOOR IDENTIFIER is a domain-controlled attribute used to identify the floor on which the facility-based asset is located.

folder_link

FOLDER LINK

FOLDER LINK is used to record the hyperlink to a folder that contains an asset’s documentation, as applicable.

GlobalID

GLOBALID

The GLOBALID is a globally unique attribute and is auto-populated when a new record is added to a feature class in the database and should not be edited by users.

height

HEIGHT

HEIGHT is used to record the physical height of an asset.

install_date

INSTALL DATE

INSTALL DATE is used to record the date than an asset was installed.

installation_type

INSTALLATION TYPE

INSTALLATION TYPE is used to record where a line asset is physically installed to aid in locating the asset in the field.

last_edited_by

LAST EDITED BY

The LAST EDITED BY attribute is auto-populated when a new record is added to a feature class in the database and should not be edited by users.

last_edited_date

LAST EDITED DATE

The LAST EDITED DATE attribute is auto-populated when a new record is added to a feature class in the database and should not be edited by users.

latitude

LATITUDE

LATITUDE is used to record the latitude of an asset. This attribute can be auto-calculated for assets during compilation if not otherwise identified.

legacy_id

LEGACY ID

LEGACY ID is used to record any existing (legacy) identifier associated with the asset or any other identifier that the asset is known by in another system.

length

LENGTH

LENGTH is used to record the physical length of an asset in feet.

line_count

LINE COUNT

LINE COUNT is used to record the number of individual assets associated with a line asset record.

line_mode

LINE MODE

LINE MODE is used to record the mode (ex. Single-Mode, Multi-Mode, etc.) associated with a linear asset.

location

LOCATION

LOCATION is a domain-controlled attribute used to record the physical location of an asset (i.e. Facility Yard, Parking Lot, Left Shoulder, Right Shoulder, etc.).

longitude

LONGITUDE

LONGITUDE is used to record the longitude of an asset. This attribute can be auto-calculated for assets during compilation if not otherwise identified.

maintained_by

MAINTAINED BY

MAINTAINED BY is a domain-controlled attribute used to record the organization responsible for maintaining an asset (i.e. MDTA, MDOT SHA, Baltimore City, etc.).

manufacturer

MANUFACTURER

MANUFACTURER is used to record an asset’s manufacturer, if known.

milemarker

MILEMARKER

MILEMARKER is used to record the value of the closest MDTA milemarker to an asset, if applicable.

milemarker_end

MILEMARKER END

MILEMARKER END is used to record the value of the closest ending milemarker for a linear asset segment, if applicable.

milemarker_start

MILEMARKER START

MILEMARKER START is used to record the value of the closest starting milemarker for a linear asset segment, if applicable.

milepoint

MILEPOINT

MILEPOINT is used to record the value of the closest MDOT SHA Mile Point (100th) to an asset, if applicable.

milepoint_end

MILEPOINT END

MILEPOINT END is used to record the value of the closest ending milepoint for a linear asset segment, if applicable.

milepoint_start

MILEPOINT START

MILEPOINT START is used to record the value of the closest starting milepoint for a linear asset segment, if applicable.

model_number

MODEL NUMBER

MODEL NUMBER is used to record the model number of an asset, if known.

mounting_type

MOUNTING TYPE

MOUNTING TYPE is a domain-controlled attribute used to record where an asset is physically mounted.

mxclassificationpath

MX

CLASSIFICATION

PATH

MXCLASSIFICATIONPATH is an attribute to map facility-based asset to its respective classification in Maximo.

mxcreationstate

MX

CREATIONSTATE

MXCREATIONSTATE is an attribute that is read by Maximo to determine whether a facility-based asset should be brought into Maximo.

mxlocation

MXLOCATION

MXLOCATION is a domain-controlled attribute that consists of building IDs as they appear in Maximo. This attribute is mapped to asset location in Maximo.

mxstatus

MXSTATUS

MXSTATUS is a domain-controlled attribute mapped to Asset Status in Maximo.

mxtype

MXTYPE

MXTYPE is a domain-controlled attribute mapped to Asset type in Maximo.

OBJECTID

OBJECTID

OBJECTID is the sequential unique whole numbers that are automatically generated within an attribute table.

other_link

OTHER LINK

OTHER LINK is used to record the hyperlink to any other folder or file that contains information about an asset, as applicable.

owner

OWNER

OWNER is a domain-controlled attribute used to record the organization that owns an asset (i.e. MDTA, MDOT SHA, Baltimore City, etc.)

phase

PHASE

PHASE is an expression of relative displacement between or among waves having the same frequencies.

photo_link

PHOTO LINK

PHOTO LINK is used to record the hyperlink to a photo of the asset.

plan_link

PLAN LINK

PLAN LINK is used to record the hyperlink to an asset’s plan(s), as applicable.

plan_sheet

PLAN SHEET

PLAN SHEET is used to record the specific plan sheet(s) (pages) on which information about an asset is found, if applicable.

removed_date

REMOVED DATE

REMOVED DATE is used to record the date than an asset was physically removed from service.

road_direction

ROAD DIRECTION

ROAD DIRECTION is used to record the traffic flow direction of the road along which an asset is located.

road_name

ROAD NAME

ROAD NAME is used to record the official name of the road along which an asset is located.

route_id

ROUTE ID

ROUTE ID is used to record the MDOT SHA Centerline ROUTEID_RH field value.

serial_number

SERIAL NUMBER

SERIAL NUMBER is used to record an asset’s serial number, if known.

service_status

SERVICE STATUS

SERVICE STATUS is a domain-controlled attribute used to record an asset’s current service status (ex. In-Service, Retired, Abandoned, Missing, etc.)

SHAPE

SHAPE

Coordinates defining the features.

space_GUID

SPACE GUID

SPACE GUID is an attribute to track the Global ID of the related room feature, if known.

space_ID

SPACE

IDENTIFIER

SPACE IDENTIFIER is an attribute used to identify the room in which the asset is located, if known.

spur

SPUR

SPUR is used to identify whether a route is a Mainline, Spur, or Ramp.

task_number

TASK NUMBER

TASK NUMBER is used to record the task number(s) associated with an asset.

voltage

VOLTAGE

VOLTAGE is used to record the voltage (electromotive force) of an asset.

wattage

WATTAGE

WATTAGE is used to record the wattage (electrical power) of an asset.

width

WIDTH

WIDTH is used to record the physical width of an asset.
